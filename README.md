# MAXIII  -  Marketing Website (`maxiii.app`)

An art-directed, cinematic, Awwwards Site of the Day caliber marketing website for **MAXIII**  -  the mobile calorie and macro tracker built for Indian food, lifters, and everyday home cooking.

---

## Tech Stack
- **Framework**: Vite + React 18 + TypeScript
- **Routing**: React Router DOM (`/`, `/features`, `/join`, `/privacy`, `/terms`, `*` 404)
- **Animation & Timelines**: GSAP + ScrollTrigger + Lenis for smooth scroll; Framer Motion for route wipes
- **Styling**: Plain CSS Modules with CSS variables as design tokens (No Tailwind, no generic UI kits)
- **Typography**: Anton (condensed display) + Bodoni Moda (high-contrast serif italics and display)
- **Deployment**: Vercel (`vercel.json` SPA rewrites & security headers) + custom domain `maxiii.app`
- **Backend / Waitlist**: Serverless Function (`/api/waitlist.ts`) with Supabase table & Formspree support

## Environment Variables & Backend Setup

Copy `.env.example` to `.env`:
```bash
cp .env.example .env
```

### Option A: Supabase (Recommended)
1. In your Supabase project, execute this SQL:
```sql
create table waitlist (
  id bigint generated by default as identity primary key,
  email text unique not null,
  role text,
  source text,
  created_at timestamp with time zone default timezone('utc'::text, now()) not null
);
```
2. Add your keys to `.env`:
```env
SUPABASE_URL=https://your-project.supabase.co
SUPABASE_SERVICE_ROLE_KEY=your-service-role-key
```

### Option B: Formspree
If using Formspree instead:
```env
FORMSPREE_FORM_ID=your_form_id
```

## Deploying to Vercel & Connecting `maxiii.app`

### 1. Push to GitHub
```bash
git add .
git commit -m "feat: complete Awwwards-caliber MAXIII marketing site"
git push origin main
```

### 2. Import into Vercel
1. Go to [vercel.com](https://vercel.com) & click **Add New Project**.
2. Select repository `MAXIII`.
3. Framework Preset: **Vite**.
4. In **Environment Variables**, add `SUPABASE_URL` and `SUPABASE_SERVICE_ROLE_KEY`.
5. Click **Deploy**.

### 3. Connect `maxiii.app` Domain
1. In Vercel Project Settings &rarr; **Domains**, enter `maxiii.app` and `www.maxiii.app`.
2. In your DNS provider (Dynadot / registrar):
   - **A Record**: `@` &rarr; `76.76.21.21`
   - **CNAME Record**: `www` &rarr; `cname.vercel-dns.com`
3. SSL certificates provision automatically within minutes.
